# Atatürk University – Alternative Website

An alternative, responsive redesign of the Atatürk University website, built for my **Web Design and Programming** course.

**🔗 Live demo:** https://yusufutkubeygo.github.io/ataturk-university-website/

## What's inside

- **20 pages:** home, faculties, institutes, vocational schools, undergraduate programs, academic and exam calendars, course registration, announcements, research centers, technopark, student clubs, campus shuttle times, cafeteria menu and more
- **Responsive layout** with Bootstrap 4 grid and a collapsible navbar
- Shared styles in `css/ortak.css`, plus one stylesheet per page
- Font Awesome icons, semantic sections and comments explaining each block

## Tech

HTML5 · CSS3 · Bootstrap 4 · Font Awesome · jQuery

## Structure

```
HTML/     pages (entry: ATA_ÜNİ.HTML)
css/      ortak.css (shared) + one file per page
images/   logos and service icons
```

## Run locally

Open `HTML/ATA_ÜNİ.HTML` in a browser. No build step needed.
